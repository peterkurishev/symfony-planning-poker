# UC-03. Создание комнаты для оценки

Пользователь создаёт комнату, выбирает шкалу и получает ссылку-приглашение для команды.

## Акторы
- Пользователь (основной), после создания — Владелец комнаты
- Участник (в подсценарии присоединения)
- Система

## Предусловия
- Пользователь авторизован (UC-02).

## Триггер
Пользователь нажимает «Создать комнату».

## Основной сценарий
1. Пользователь вводит название комнаты.
2. Пользователь выбирает шкалу оценки: Фибоначчи, степени двойки или произвольная (см. UC-05). Для произвольной вводит список значений.
3. Пользователь задаёт длительность таймера по умолчанию для раундов (например, 60 секунд).
4. Система проверяет данные: название от 2 до 100 символов, шкала валидна, таймер от 10 секунд до 30 минут.
5. Система создаёт комнату, назначает пользователя владельцем и участником, генерирует уникальный код приглашения.
6. Система показывает страницу комнаты со ссылкой-приглашением вида `/rooms/join/{code}` и кнопкой «Скопировать».

## Альтернативные сценарии
- **4а. Невалидные данные.** Система показывает ошибки у полей.
- **Смена шкалы.** Владелец может изменить шкалу комнаты, пока нет активного раунда. Задачи с уже зафиксированной оценкой сохраняют её как есть.
- **Перегенерация ссылки.** Владелец может сгенерировать новый код; старая ссылка перестаёт действовать.

## Подсценарий: присоединение к комнате по ссылке
1. Пользователь открывает ссылку-приглашение.
2. Если он не авторизован, система перенаправляет на вход (UC-02) и после входа возвращает по ссылке.
3. Система находит комнату по коду и добавляет пользователя в участники (если он ещё не участник).
4. Система уведомляет остальных участников о новом участнике в реальном времени.
5. Система показывает страницу комнаты: список задач, участников, текущее состояние раунда.
- **3а. Код не найден или отозван.** Система показывает страницу «Комната не найдена».

## Постусловия
- Создана комната с владельцем, шкалой, таймером по умолчанию и кодом приглашения.
- Присоединившийся пользователь числится участником комнаты.

## Примечания к реализации
- PostgreSQL: `rooms` (id, name, owner_id, scale_type, scale_values jsonb, default_timer_sec, invite_code unique, created_at); `room_members` (room_id, user_id, joined_at).
- Код приглашения: случайная строка 10–12 символов (base62), генерируется через `random_bytes`.
- Realtime-событие `member.joined` через Mercure topic `room/{id}`.
