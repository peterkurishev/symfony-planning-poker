# HTTP API

Базовый URL: `http://localhost:8080/api`. Аутентификация — сессионная cookie, формат тела и ответов — JSON.
Ошибки возвращаются как `{"message": "..."}`, ошибки валидации регистрации дополнительно содержат `errors` по полям.

## Аутентификация (UC-01, UC-02)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/register` | `{email, name, password}` — регистрация и автоматический вход |
| POST | `/login` | `{email, password}` — вход, не более 5 попыток за 15 минут |
| POST | `/logout` | выход |
| GET | `/me` | текущий пользователь |

## Комнаты (UC-03, UC-05)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/rooms` | комнаты, где пользователь участник |
| POST | `/rooms` | `{name, scale_type, scale_values?, default_timer_sec?}` |
| GET | `/rooms/{id}` | комната с задачами и участниками |
| PATCH | `/rooms/{id}` | владелец меняет название, шкалу, таймер |
| POST | `/rooms/{id}/invite` | новый код приглашения, старый отзывается |
| POST | `/rooms/join/{code}` | присоединиться по ссылке-приглашению |

`scale_type`: `fibonacci`, `pow2`, `custom`. Для `custom` в `scale_values` передаётся строка через запятую или массив: от 2 до 30 уникальных значений до 10 символов.

## Задачи (UC-04)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/rooms/{id}/tasks` | `{title, description?, external_url?}` |
| PATCH | `/tasks/{id}` | правка, запрещена при активном раунде |
| DELETE | `/tasks/{id}` | удаление, запрещено при активном раунде |
| POST | `/rooms/{id}/tasks/reorder` | `{task_ids: [...]}` — новый порядок |

## Раунды и голоса (UC-06, UC-07, UC-08)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/tasks/{id}/rounds` | владелец запускает раунд, `{duration_sec?}` от 10 до 1800 |
| GET | `/rounds/{id}` | состояние раунда |
| POST | `/rounds/{id}/finish` | досрочная остановка владельцем |
| POST | `/rounds/{id}/vote` | `{value}` — голос участника |
| DELETE | `/rounds/{id}/vote` | отмена голоса |
| POST | `/tasks/{id}/estimate` | `{final_estimate}` — владелец фиксирует итог |

У активного раунда отдаётся только `voted_user_ids`. Значения голосов и блок `stats` появляются после завершения. Статистика содержит среднее, медиану, предложенное значение шкалы, распределение, моду и признак большого разброса.

## Realtime

События комнаты пишутся в поток Redis `room:{id}:events`: `member.joined`, `room.updated`, `task.created`, `task.updated`, `task.deleted`, `task.reordered`, `round.started`, `vote.cast`, `vote.retracted`, `round.all_voted`, `round.finished`, `task.estimated`. Доставка в браузер подключается на шаге фронтенда.

## Таймер

Запуск раунда отправляет отложенное сообщение в очередь Redis, воркер `messenger:consume async` завершает раунд по дедлайну. Обработчик идемпотентен. При сбое воркера просроченный раунд закрывается лениво при следующем обращении к комнате или раунду.
