## Роли (акторы)

- **Гость** — неавторизованный посетитель. Может только зарегистрироваться или войти.
- **Пользователь** — авторизованный посетитель. Может создавать комнаты и присоединяться к ним по ссылке.
- **Владелец комнаты** — пользователь, создавший комнату. Управляет задачами, шкалой, запуском и остановкой оценки, фиксирует итог.
- **Участник** — пользователь, присоединившийся к комнате. Голосует за оценку. Владелец также является участником.
- **Система (таймер)** — фоновый процесс, автоматически останавливающий раунд по истечении времени.

## Глоссарий

- **Комната** — пространство для командной оценки. Имеет владельца, шкалу, список задач, участников и уникальный код приглашения.
- **Ссылка-приглашение** — URL с кодом комнаты. Любой пользователь, перешедший по ней, становится участником.
- **Задача** — единица оценки внутри комнаты: название, описание, итоговая оценка.
- **Шкала** — упорядоченный набор допустимых значений оценки: Фибоначчи, степени двойки или произвольная.
- **Раунд оценки** — период голосования по одной задаче: имеет время старта, длительность таймера, статус (`active` / `finished`).
- **Голос** — выбранное участником значение шкалы в рамках раунда. Скрыт от остальных до окончания раунда.
- **Итоговая оценка** — значение, зафиксированное владельцем по результатам раунда.

## Общие правила

- В комнате одновременно может быть активен только один раунд.
- Голоса скрыты до остановки раунда; до этого видно только, кто уже проголосовал.
- После остановки система показывает все голоса, среднее и медиану; владелец фиксирует итоговую оценку.
- Все изменения состояния комнаты (новая задача, старт/стоп раунда, факт голосования, вход участника) доставляются участникам в реальном времени.

## Общие замечания по реализации

- **PostgreSQL** — долговременные данные: пользователи, комнаты, задачи, шкалы, завершённые раунды и голоса, итоговые оценки.
- **Redis** — состояние активного раунда (голоса до раскрытия, дедлайн таймера), сессии, pub/sub для realtime-событий.
- **Realtime** — Mercure (штатная интеграция Symfony) либо WebSocket; фронтенд на Vue подписывается на события комнаты.
- **Таймер** — ключ раунда в Redis с TTL плюс воркер (Symfony Messenger с отложенной доставкой), который завершает раунд по дедлайну.
