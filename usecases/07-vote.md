# UC-07. Оценка задачи

Участник выбирает значение шкалы для задачи в активном раунде.

## Акторы
- Участник (основной)
- Система

## Предусловия
- Участник состоит в комнате (UC-03).
- В комнате есть активный раунд (UC-06), дедлайн не наступил.

## Триггер
Участник нажимает карточку со значением шкалы.

## Основной сценарий
1. Участник выбирает значение из карточек шкалы комнаты (UC-05), включая `?` и `☕`.
2. Система проверяет: раунд активен, дедлайн не прошёл, значение входит в шкалу, участник состоит в комнате.
3. Система сохраняет голос участника в раунде (перезаписывая предыдущий, если был).
4. Система подтверждает участнику его выбор (карточка выделяется).
5. Система уведомляет всех участников, что данный участник проголосовал, не раскрывая значение.
6. Если проголосовали все участники комнаты, система уведомляет владельца, что можно остановить раунд досрочно (UC-08).

## Альтернативные сценарии
- **2а. Раунд уже завершён (по таймеру или вручную).** Система отклоняет голос и показывает результаты раунда.
- **2б. Значение не из шкалы.** Система отклоняет запрос с ошибкой 422.
- **2в. Пользователь не участник.** Ошибка 403.
- **Изменение голоса.** Участник до окончания раунда может выбрать другую карточку; учитывается последний выбор.
- **Отмена голоса.** Участник повторно нажимает выбранную карточку; голос снимается, остальные видят, что он ещё не проголосовал.
- **Участник не проголосовал до дедлайна.** Раунд завершается без его голоса; в результатах он отмечен как «не голосовал».

## Постусловия
- В активном раунде сохранён голос участника (или отсутствует, если отменён).
- Остальные участники видят факт голосования, но не значение.

## Примечания к реализации
- Redis: `HSET round:{id}:votes {user_id} {value}` — атомарная перезапись; `HDEL` для отмены. Проверка активности раунда и дедлайна выполняется на сервере по `deadline_at` из Redis.
- Голоса переносятся в PostgreSQL (`votes`: round_id, user_id, value) при завершении раунда (UC-08).
- Realtime-событие `vote.cast` / `vote.retracted` с `user_id`, без значения. Владелец получает `round.all_voted`.
- Vue: состояние «проголосовал/нет» отображается на аватарах участников.
